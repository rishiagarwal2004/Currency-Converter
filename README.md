# 💱 Currency Converter

A simple and responsive Currency Converter web application built using **HTML, CSS, and JavaScript**. The application fetches real-time exchange rates and allows users to convert currencies instantly.

## 🌐 Live Demo

🔗 https://spectacular-souffle-c83d23.netlify.app/

> Replace the above link with your latest deployed URL if it changes.

## 🚀 Features

* 🌍 Convert between multiple international currencies
* ⚡ Real-time exchange rates using API
* 🎨 Clean and user-friendly interface
* 📱 Fully responsive design
* 🔄 Instant conversion on input changes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* ExchangeRate API

## ⚙️ Installation & Usage

1. Clone the repository

```bash
git clone https://github.com/rishiagarwal2004/currency-converter.git
```

2. Navigate to the project folder

```bash
cd currency-converter
```

3. Open `index.html` in your browser.
